# Soultemis changelog

## v0.1.0-soultemis-preview.1

Initial public test preview.

### Added and customized
- Independent Soultemis Android application identity and icon.
- DS4 controller touchpad interface, touch contacts and click controls.
- Two-finger visual tracking and click-state feedback.
- Configurable overlay placement, sizing and opacity.
- Touchpad preferences and optional tap-to-click / long-press-to-click.
- Compact floating touchpad toggle and optional diagnostics.
- Compatibility with Artemis's normal mouse mode when the DS4 touch surface is not shown.

### Known limitations
- Tested configurations are limited; controller assignment can differ when multiple physical gamepads are attached.
- Apollo must emulate a DS4 for DS4 touch contacts to work on Windows.
- Initial downloadable APK is debug-signed.
- Soultemis's local Xbox/DS4 UI setting does not automatically detect host-side mode changes.
